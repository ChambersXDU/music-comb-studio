# 音乐梳子读谱与序列

交付可追溯的音符序列：能指出每段来自哪份谱，哪些音被简化，如何移调，最终每个梳齿对应什么音。用户可以只给歌名和歌词范围，不需要先提供模型。

## 找谱与读谱

用户提供谱时优先读该谱，否则搜索带歌词对位的主旋律谱。查看实际谱图或 PDF，记录来源网址、制谱者、调号和指定片段；搜索摘要、和弦名和伴奏谱不能替代主旋律。模糊或冲突的符号，先放大或用另一份可读谱核对，并标明仍不确定的位置。

先读出原始音高、八度、升降号、休止、同音延音线和歌词对位，再决定简化。简谱按谱面的 `1=…` 和上下八度点转换；五线谱读谱号、调号与临时变音。圆滑线不表示所有音合成一个音，真正的延音线只连接同音。不同歌词上的同音再发音应保留两个事件。

独立读谱任务不得从已有模型反推答案后声称“从谱得出”。已有 3MF 可以在读谱、简化和移调完成后作为独立比较基准；不能为了吻合模型而悄悄修改原始转写。只有从几何反推时，应明确写“从模型还原序列”，不能称为独立读谱或直接保证实物频率。

## 简化与音域

沿用用户指定的简化程度。用户没有具体规则时，给出一个用于试做的版本：保留旋律走向、主要音、明显再发音和句末落音，优先省略快速倚音、短回转和装饰性经过音。不要为了凑齿数把所有字强行改为一字一齿；一字多音可保留，跨字同音也不能任意合并。

保留原始转写，再单独记录删减或合并，例如“此字的 3→2→3 回转保留主音 3”。装饰音删除后是否合并相邻同音属于明确的简化选择，不能自动把全部重复音去重。用户要完整转音时按谱保留。

先确定原调，再选择目标调和整体八度，使片段落入项目支持的音域；整段统一移调，保留半音关系，不能逐音折叠八度或就近替换超范围音。没有要求移调且原调可用时保留原调；沿用已有模型调高属于特定用户选择，不是某首歌的通用规则。若范围无法容纳，说明具体超范围音，再给可行的整体移调或片段拆分方案。

读 [references/sequence-format.md](references/sequence-format.md) 获取标签、逻辑音域、JSON 字段和转换脚本。特别注意生成器的 `C1` 是项目标签，不等于科学音高 C1。项目上限为 33 齿，不自动截断或加入无意义空白凑数。

## 停顿与输出验证

默认保留谱中的休止，每个休止段用一个 `·` 标记，不按时值展开成多个位置；实物由用户手动控制停顿长短。不要把每条小节线都当停顿，也不要把同音延音线变成重新拨奏。句间呼吸或为方便辨认而额外加入的停顿，应标为简化选择，不能伪称来自谱面。停顿也计入 8–33 个位置，超过上限时拆分片段，不偷偷删休止。实物的空白细齿不能保证无声，需要在该位置跳过或停手。

用歌词片段和音符的对位记录核对漏音、重复音、装饰音和延音；指明原调、目标调、整体八度及简化选择。可用 `scripts/make_sequence.py` 将已经简化的科学音高事件确定性转换为序列、方案 JSON 和逐齿对位记录；脚本不负责图像读谱或判断旋律主音。

交付一条空格分隔的可复制序列，及需要的方案 JSON。用户要模型时，调用 music-comb-studio 的共享 CLI；用户要网页输入时，通过现有网页替换序列并确认模型更新，保留现有颜色和图文设置。不要仅报告“已输入”而未检查错误和生成结果。

有参考序列时，在统一标签、调高和片段范围后逐项比较，报告首个差异与差异类型。片段较短而参考含下一句，说明截取范围，不能声称两份完整谱相同。比较时同时核对音高和停顿位置。网页试听每格 0.28 秒，`·` 不发声，只用于辨认旋律；停顿标记不编码原曲精确时值。实物仍需打印后校准。

将结果写成用户操作所需的简短说明。完整谱图和整首歌词不必复制到输出或公开仓库；保留来源链接和此次片段的转写记录即可。发布模型或上传仓库仅在用户明确要求时执行，调用此 skill 本身不授予发布权限。
